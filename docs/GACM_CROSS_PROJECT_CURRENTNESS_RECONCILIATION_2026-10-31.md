## 4. Repeatable lessons to promote only after approval and proof

- **Sanity migration source integrity:** bind source identity to exact content hash, revision and destination ID. Repair stale lineage with collision/revision protection; do not overwrite a content/asset or protected draft. Record separate import, readback, preview, browser edit persistence, published perspective and full visual/interaction parity.
- **Sanity Studio ↔ Preview protection:** a READY Preview or 200 endpoint is not iframe or SSO acceptance. Check actual authenticated Presentation handshake, cross-origin cookies/headers, save/reload, clicks, draft isolation and responsive behavior. Do not expose a shared bypass secret, change protection or make a public exception without explicit authority.
- **Sanity PageBuilder/TypeGen:** derive schema → Studio extraction → generated types → GROQ projection → component rendering → Markdown output; avoid treating one fixed query or route as generalized acceptance.
- **Whole-site acceptance artifact:** a missing independently generated, exact-SHA bound `.gacm/fullsite-acceptance.json` is HOLD, not a request to synthesize proof. Verify route coverage, interactions, source parity, published delivery, links, accessibility/mobile and invariants at the actual required execution surface.
- **Runtime reliability:** local server port availability, Next dev stability and Playwright access are distinct from repository correctness. Prefer explicitly authorized stable isolated Preview when local runtime is an obstacle. Do not blindly restart/delete, occupy unrelated ports, or repeat a network/SSO probe after an access-boundary diagnosis.
- **Currentness across project boundaries:** each project maintains its *own* canonical current state and accepted contract; the GACM register is an index/pointer with observed date and proof quality, not a copy promoted over newer project authority.
- **Autonomous orchestration:** never infer working repeated-run scheduling from `run_codex` alone. Require independent authorization, durable contract digest, single active run, bounded repeats, crash recovery, exact evidence receipts, true budget accounting and explicit STOP at tranche end.
- **Content factory scope:** FCF-00 is read-only discovery **after** Falardeau 016 closure, not automatic continuation. Proposed improvement covers repeatable source extraction, mapping, assets, draft safety, structural and visual/edit parity, rollback and proof.
