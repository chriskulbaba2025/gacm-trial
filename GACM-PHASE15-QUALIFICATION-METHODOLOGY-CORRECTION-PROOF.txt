ROOT CAUSE
The existing PilotHarness performs execute -> verify -> repair -> reverify inside the per-work-unit loop.
That makes qualification discovery serial: an ordinary product divergence triggers repair before later safe qualification surfaces are observed.

CORRECTION
Added a finite Qualification Graph control that:
- maps every normative frozen SPEC requirement to at least one qualification node;
- rejects any qualification node that does not map back to the frozen SPEC;
- requires authoritative independent completeness PASS tied to the same SPEC digest before graph freeze;
- freezes an immutable graph denominator and deterministic digest;
- separates sandbox-safe discovery from mutation/repair;
- continues safe discovery after ordinary product failures;
- hard-stops on unsafe authority/security/external-state conditions;
- clusters failures by invariant/root-cause class;
- computes transitive retest closure for bounded repairs;
- enforces a fixed adversarial escape-scan budget;
- reports completion as UNAVAILABLE before graph freeze;
- defines explicit machine-checkable termination conditions.
